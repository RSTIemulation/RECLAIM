# RECLAIM — Motherhood, Wellness & Purpose

A clickable, mobile-first **private prototype** of a recovery-first wellness and intentional-living companion for mothers. The product celebrates strong family relationships, compassion, practical support, personal responsibility, and personal growth without requiring any faith affiliation.

## Try it right away

- Open `RECLAIM-preview.html` in a browser. This is a **standalone preview file** and does not need a server or other files.
- For a proper installable app, upload `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, and the complete `icons/` folder to the **root** of a GitHub repository.
- Enable **Settings → Pages → Deploy from branch → main → /(root)**, and wait for the site to become available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
- Open the HTTPS URL on your phone; choose **Chrome → ⋮ → Add to Home screen / Install app** or **Safari → Share → Add to Home Screen**.

## The prototype includes

- Guided, three-minute onboarding: focus areas, time available, children's ages (optional), coaching style
- Three adjustable stages: Restore, Rebuild, Rise (never gated)
- Energy-responsive daily action suggestions from a curated library (constrained by available time)
- Completion checkboxes, alternative activities, ability to take a restorative day
- Family-connection ideas, favorites, and optional bonus actions
- Weekly action chart, reflection journal, and intentions
- Profile preferences, export/import JSON, and erase-my-data controls
- Responsive interface and icons; PWA manifest + offline service worker for hosted version

## Important product boundaries

This is a **non-clinical concept** and not a mental-health diagnosis, medical treatment, or substitute for care. It does not use AI, make medical inferences, conduct assessments, or collect information from a server. It doesn't prescribe fasting or restrictive diets. Consenting mothers and qualified maternal-health professionals should be consulted **before clinical claims or wider user testing**. In urgent danger call local emergency services. In the U.S., call or text 988 for crisis support.

## Privacy in this first version

All answers, reflections, and activity progress are saved to the current browser's `localStorage`. They are **not encrypted** at rest and could be accessed by another person who controls the device/browser. There is no account system or automatic cross-device sync. Use a private testing device, not sensitive real-world patient records. Clearing browser data erases history unless backed up. Backup JSON files themselves contain personal information and should be protected.

## Product maturity

This prototype has no production authentication, cloud database, analytics, subscriptions, push notifications, or formal clinical/security review. It is for design validation, not a clinical or commercial launch. Be aware that the RECLAIM name and brand marks are **not checked for trademark availability**.
